# Why parameters are weak levers (after Meadows, ch.6)

A parameter is a number in a system: a tax rate, a thermostat setpoint, a subsidy. Meadows argues that changing
parameters rarely changes how a system behaves, because behaviour is produced by the feedback structure, the
loops and delays between stocks, and parameters only tune that structure without changing it. Decades of tax rate
tweaks that left deficits in place support the claim. Raising a thermostat setpoint is the textbook example: the
room gets warmer, but the heater responds the same way.

The claim has limits. An interest rate can push a reinforcing loop past a threshold and trigger runaway
behaviour, which attacks the claim and raises an open question: when does a parameter cross a threshold and
reshape structure?
